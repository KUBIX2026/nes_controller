# Testbench para observación de señales en controlador NES
Se realiza un testbench con el objetivo de simular la consola sin conectar la FPGA (y por ende, el mando físico). Esto permite reducir la probabilidad y cantidad de errores que puedan surgir a la hora de estimar y probar el protocolo de comunicaciones emitido por la consola hacia el mando.
